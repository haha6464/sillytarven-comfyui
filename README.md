# 本轮生图（SillyTavern 扩展）

这是一个精简版 ComfyUI 扩展：在每条 AI 回复上点击“生成图片”，扩展只发送该条回复给配置的 OpenAI 兼容 LLM；LLM 输出场景提示词后，扩展把它写入 ComfyUI 工作流的正向提示词节点并生成一张图。

默认工作流来自 \`Krea-标准生图.json\`，正向提示词位置为节点 \`5\` 的 \`text\` 字段。可在酒馆的扩展设置中导入/粘贴任意 ComfyUI API 格式工作流，并修改该节点 ID 与字段名。

## 配置

1. 打开酒馆的 Extensions 设置，展开“本轮生图设置”。
2. 填写 ComfyUI 地址、LLM Base URL（须含 \`/v1\`）、API Key 和模型名。
3. 按需编辑“LLM 场景总结提示词”；\`{{message}}\` 会被替换成当前那一条 AI 回复，历史消息不会发送。
4. ComfyUI 或 LLM 出现跨域时，保留“通过酒馆代理”开启；直连仅适用于相应服务已允许 CORS 的情况。

图片保存在当前聊天消息的扩展数据中，刷新聊天后仍会显示。

生图时悬浮按钮显示 ComfyUI 实时采样步数（如 `3/9`），加载和保存时显示等待点，完成后显示勾号。进度使用 ComfyUI WebSocket，图片请求仍支持酒馆代理。手机使用代理且 ComfyUI 地址为 localhost 时，进度自动连接酒馆主机的同一 ComfyUI 端口；需要该端口允许手机访问。浏览器无法连接进度（例如端口未开放、HTTPS 页面访问不安全的 WS）时会保留等待点，不影响出图。
