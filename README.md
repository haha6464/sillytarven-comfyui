# 本轮生图（SillyTavern 扩展）

这是一个精简版 ComfyUI 扩展：在每条 AI 回复上点击“生成图片”，扩展只发送该条回复给配置的 OpenAI 兼容 LLM；LLM 输出场景提示词后，扩展把它写入 ComfyUI 工作流的正向提示词节点并生成一张图。

默认工作流来自 \`Krea-标准生图.json\`，正向提示词位置为节点 \`5\` 的 \`text\` 字段。可在酒馆的扩展设置中导入/粘贴任意 ComfyUI API 格式工作流，并修改该节点 ID 与字段名。

## 配置

1. 打开酒馆的 Extensions 设置，展开“本轮生图设置”。
2. 填写 ComfyUI 地址、LLM Base URL（须含 \`/v1\`）、API Key 和模型名。
3. 按需编辑“LLM 场景总结提示词”；\`{{message}}\` 会被替换成当前那一条 AI 回复，历史消息不会发送。
4. ComfyUI 或 LLM 出现跨域时，保留“通过酒馆代理”开启；直连仅适用于相应服务已允许 CORS 的情况。
5. 种子默认 `-1`，每次提交时插件会把 `{{seed}}` 替换为实际随机整数，兼容 rgthree Seed 和原生 KSampler；`0` 和正数是固定种子。更新不会覆盖已保存的固定种子，已有配置需要手动改为 `-1`。

图片文件上传到酒馆账号的 `user/images/scene-draw/` 目录，路径保存在聊天消息的扩展数据中，刷新聊天后仍会显示。

总结弹窗中，“提交”会先保存本条消息的 prompt、分辨率比例和全部 LoRA 滑块，保存成功后才开始生图；保存失败会保留弹窗且不触发生图，生图失败或中断也会保留本次已保存的配置。“提交”下方的“保存”只保存配置，不触发生图，保存后弹窗保持打开。之后重新打开优先恢复该条消息自身配置；尚无自身配置的消息沿用全局上次选择，旧数据不迁移。

同一条消息再次生图会追加到图集中，默认显示新图；点击图片两侧箭头翻页，右上角垃圾桶删除当前图片，下载按钮下载当前页。图集和当前页随聊天保存，旧版本的单张图片自动兼容。

图片按聊天滚动区域加载：图片区域距离可见区域约 600px 时，提前请求该图集当前显示的原图；其余图片翻页后再加载。不生成预览图、不预加载整套图集，也不增加设置项。尚未加载时按消息的图片比例预留位置，减少滚动跳动；缓存中已完成的图片直接显示，不等待滚动观察。页面变化只检查受影响的消息，合并到每帧处理；不支持可见区域观察的旧浏览器会退回普通加载。此优化减少同时请求的原图数量，不改变单张原图大小和网络传输速度。

## 图片文件清理（需一次性安装服务端模块）

在运行酒馆的设备上执行：`node /插件绝对路径/server/install.cjs /SillyTavern绝对路径`，然后重启酒馆。安装程序在 `plugins/scene-draw-files` 建立链接并开启 `enableServerPlugins`，保留 `config.yaml.scene-draw-backup` 备份；以后更新前端插件也会更新链接中的服务端代码。扩展设置中可点击“检查图片清理服务”。未安装模块时，垃圾桶会提示安装，不会悄悄只移除记录。

图集删除会先保存聊天，再检查所有当前单聊、群聊及分支存档，最后删除已无引用的对应文件。删除聊天或消息后也会清理此前登记且失去最后引用的图片。扫描失败或仍存在引用时保留文件。聊天备份和导出的副本不属于当前聊天引用；清理后的图片无法通过旧备份恢复。服务仅清理酒馆副本，不涉及 ComfyUI 输出目录。

历史无引用图片不会在安装、启动或普通清理时自动删除；旧版时间戳图片若已经失去全部插件记录，不能仅凭文件名确定来源。只读检查命令：`node /插件绝对路径/server/audit.cjs /SillyTavern绝对路径/data/账号目录`，报告列出绝对路径和文件大小，不删除文件。

总结弹窗中的 LoRA 滑块依次为人物、`penis_size`、zoom。`penis_size_krea2_v2_loraholic` 支持 -8～5、步长 0.5，同时调整模型和 CLIP 强度；首次使用沿用工作流的强度，此后跨聊天记忆上次选择。自定义工作流缺少对应 LoRA 时，该滑块禁用。

人物滑块切换时，会把弹窗当前 prompt 中旧角色的中文全名替换为新角色全名；没有匹配的人名则保留原文。替换结果需点击“保存”或“提交”才写入本条消息。

李蕊男滑块始终显示“李蕊男”，实际版本以用户工作流中 LoRA Manager 配置的 `LiRuinan_v…` 文件为准，不强制转换 v2/v4。已有消息中的李蕊男选择会跟随当前工作流的版本，保留配置的文件路径、扩展名和强度。如果工作流同时配置多个版本，优先使用已激活的版本，否则使用列表中第一个版本；滑块仍只有一个李蕊男选项。

生图时悬浮按钮显示 ComfyUI 实时采样步数（如 `3/9`），加载和保存时显示等待点，完成后显示勾号。进度使用 ComfyUI WebSocket，图片请求仍支持酒馆代理。手机使用代理且 ComfyUI 地址为 localhost 时，进度自动连接酒馆主机的同一 ComfyUI 端口；需要该端口允许手机访问。浏览器无法连接进度（例如端口未开放、HTTPS 页面访问不安全的 WS）时会保留等待点，不影响出图。

生图期间会出现小方块中断按钮，仅取消本次任务，不清空队列或发送全局中断。需要浏览器能访问 ComfyUI，且 ComfyUI 支持 `/api/jobs/{id}/cancel`。排队中的中断请求会等该任务开始后立即发送，以免酒馆代理因找不到任务历史而一直等待；其他任务不受影响。中断后可重新生成，原有图片保留。
